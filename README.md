# Section 9 DOM Homework

This repository contains my JavaScript DOM Manipulation homework exercises.

## Tasks

### Task 1: Text and Style
Changes paragraph text using textContent and changes its color using the style property.

### Task 2: Simple Image Gallery
Changes the main image when different buttons are clicked using the src property.

### Task 3: To-Do List
Allows tasks to be marked as completed using classList.toggle().

### Task 4: Counter App
A counter that increases and decreases without allowing the number to go below zero.

## Concepts Practiced

- DOM Manipulation
- getElementById()
- querySelectorAll()
- textContent
- style
- src
- addEventListener()
- classList.toggle()
- Functions
- if statements
